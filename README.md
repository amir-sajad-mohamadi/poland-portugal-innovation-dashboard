# رصد نوآوری لهستان و پرتغال

داشبورد فارسی با هفت شاخص فناوری و اقتصاد، نماهای روند، تغییر سالانه، مقایسهٔ جهانی و همبستگی، و دستیار داده‌ها.

[مشاهدهٔ داشبورد](https://amir-sajad-mohamadi.github.io/poland-portugal-innovation-dashboard/)

توسعه‌دهنده **محمد قائم محمدی**

فایل index.html همهٔ داده‌ها، کد رابط و فونت موردنیاز را دارد. منبع کامل پروژه در project-source.zip قرار دارد. مجوز فونت در OFL-Vazirmatn.txt همراه پروژه است.

دستیار نسخهٔ وب سه پاسخ مرجع و بازیابی داده‌های مرتبط با سؤال را در مرورگر اجرا می‌کند. در ورود به سایت، کلید API اول‌ای‌آی درخواست می‌شود. کلید در حافظهٔ همان تب می‌ماند. دستیار برای پرسش تحلیلی از مدل کم‌هزینه استفاده می‌کند و پاسخ تکراری، سقف درخواست و سقف توکن را مدیریت می‌کند.
