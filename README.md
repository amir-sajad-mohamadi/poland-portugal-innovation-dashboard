# رصد نوآوری لهستان و پرتغال

داشبورد فارسی با هفت شاخص فناوری و اقتصاد، نماهای روند، تغییر سالانه، مقایسهٔ جهانی و همبستگی، و دستیار داده‌ها.

توسعه‌دهنده **محمد قائم محمدی**

فایل index.html همهٔ داده‌ها، کد رابط و فونت موردنیاز را دارد. منبع کامل پروژه در project-source.zip قرار دارد. مجوز فونت در OFL-Vazirmatn.txt همراه پروژه است.

دستیار نسخهٔ وب سه پاسخ مرجع و بازیابی داده‌های مرتبط با سؤال را در مرورگر اجرا می‌کند. اتصال مدل زبانی در اجرای پایتونِ منبع پروژه با تنظیمات خصوصی سرور فعال می‌شود.
